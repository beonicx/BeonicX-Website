# Welcome to BeonicX Blog

This is a sample blog post demonstrating our content structure. You can replace this with your actual content.

## Features

- **Markdown Support**: Write your posts in simple markdown
- **SEO Optimized**: Each post is automatically optimized for search engines
- **Fast Loading**: Server-side rendering ensures lightning-fast page loads

## Getting Started

To create new blog posts, simply add markdown files to the `content/blog` directory with frontmatter containing:

- title
- excerpt
- category
- tags
- author
- publishedAt
- featuredImage (optional)

Happy blogging!
